# Apply for a juggling licence

Use this service to apply for a licence to juggle in public.

You can use this service if you live in England.

:::button Start now
:::

## Before you start

You will need to tell us:

- how many balls you can juggle
- what you juggle with
- how long you have been juggling
- a photo of your best trick
- your name, phone number and email address

It takes around 5 minutes.
